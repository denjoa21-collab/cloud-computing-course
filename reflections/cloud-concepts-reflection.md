# Cloud Concepts Reflection Paper

In my daily life as a student, I use several cloud-based applications without even thinking about it. Three services I use regularly are **Google Drive**, **Netflix**, and **Canva**.

**Google Drive** is a **Software as a Service (SaaS)** because I access it directly through my web browser without installing anything. Its deployment model is **Public Cloud** since the infrastructure is owned by Google and shared with millions of users worldwide. I use it to store my school files and share them with classmates.

**Netflix** is also a classic example of **SaaS**. It is a public cloud service because it is offered over the internet to everyone with a subscription. I use it for entertainment, but technically, it is a cloud-based application that handles large amounts of video data.

**Canva**, which I use for creating presentations and infographics, is also **SaaS**. Like the others, it's a public cloud service because I just need a web browser and an internet connection to edit my designs.

I believe that **Git and GitHub are critical** in cloud computing because they serve as the "safety net" for infrastructure. When teams manage servers and applications in the cloud, a single wrong code or configuration can break the whole system. GitHub allows teams to use **version control**, meaning they can easily roll back to a previous working version if an error occurs. Furthermore, GitHub helps teams collaborate efficiently by allowing them to work on different features simultaneously without overriding each other's work. This system prevents a lot of human errors and helps in auditing changes to cloud resources, which is essential for stability and security.
